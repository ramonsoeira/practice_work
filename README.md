# practice_work

Projeto desenvolvido para o Trabalho Prático da disciplina DGT2809 — Aprofundamento em Desenvolvimento Front-End. Seu escopo corresponde ao catálogo de livros solicitado no enunciado: listagem, cadastro, exclusão, formulário e navegação em Angular. Os dados ficam em memória e voltam ao estado inicial quando a página é recarregada.

## Requisitos

- Node.js em versão compatível com Angular 22
- npm

## Como executar

Na raiz do repositório, instale as dependências e inicie a aplicação:

```bash
npm install
npm start
```

O comando `npm start` executa o `ng serve` indicado no roteiro. Abra `http://localhost:4200/` no navegador. Para gerar a versão de produção, execute:

```bash
npm run build
```
